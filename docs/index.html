Why a pairing makes this possible

A pairing is a map e : G1 × G2 → GT with one useful property: e(a·P, b·Q) = e(P, Q)a·b. Exponents move across the map, so verification is a single equality.

e(σ, Q)  =  e(H(m), pk)

pk = sk·Q and σ = sk·H(m), so both sides come out to e(H(m), Q)sk.

Edit the message after signing and verify again — the signature is bound to the exact bytes, so a single changed character fails.

Aggregate two signatures

Sign two messages, then add the signatures together. The sum is one signature, the same size as either input, and it still verifies both messages. ECDSA has no equivalent operation.

aggregate σ = σ₁ + σ₂
