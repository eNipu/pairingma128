Why a pairing makes this possible

A pairing is a map e : G1 × G2 → GT with the magic property e(a·P, b·Q) = e(P, Q)a·b. BLS verification is the single equality:

e(σ, Q)  =  e(H(m), pk)

pk = sk·Q and σ = sk·H(m), so both sides equal e(H(m), Q)sk.
